# Casa Aroma Collective

Crea una página web moderna, elegante y completamente responsive para una marca de aromas y productos de bienestar.

La página debe tomar como referencia visual el estilo de https://tph-home-showcase.vercel.app/, especialmente su estética minimalista, editorial y premium. Usa una tipografía y paleta de colores visualmente equivalentes a las de la referencia, manteniendo un diseño original y evitando copiar elementos exactos de marca, logos o textos.

El objetivo principal es presentar un catálogo de aromas inspirado en los productos disponibles en https://bekoko.cl/. Utiliza datos de ejemplo realistas para los productos, pero deja la estructura preparada para reemplazarlos fácilmente después.

## Tecnologías y requisitos

- Construye la aplicación con React, TypeScript, Tailwind CSS y componentes reutilizables.

- Usa Lucide React para los iconos.

- No uses backend por ahora.

- No implementes pagos reales.

- Debe funcionar como una landing page + catálogo navegable.

- Diseño mobile-first y totalmente responsive.

- Añade animaciones sutiles y elegantes al hacer scroll, hover y abrir el detalle de un producto.

- Mantén un código limpio, modular y fácil de editar.

## Estilo visual

- Estética minimalista, refinada, cálida y editorial.

- Diseño inspirado en una marca premium de hogar, fragancias y bienestar.

- Usa bastante espacio en blanco, tipografía grande en titulares y composiciones visuales limpias.

- La página debe sentirse artesanal, natural y sofisticada.

- Usa imágenes de producto tipo lifestyle: velas, difusores, sprays ambientales, jabones, aceites esenciales y aromas para hogar.

- Usa bordes suaves, sombras muy sutiles y transiciones delicadas.

- Evita colores chillones, elementos visuales recargados y tarjetas excesivamente redondeadas.

## Paleta de colores

Crea variables CSS o clases Tailwind fáciles de editar.

Paleta sugerida:

- Fondo principal: crema muy claro / beige cálido.

- Fondo secundario: blanco roto.

- Texto principal: marrón oscuro o negro cálido.

- Texto secundario: gris taupe.

- Acento: terracota suave, verde salvia o beige oscuro.

- Botones principales: marrón oscuro con texto claro.

- Botones secundarios: transparentes con borde fino oscuro.
